# BIOE591 Coursework Repository

## Description
This repository is where I will store and edit my coursework for BIOE 591: Genomics for Ecology & Evolution

## Directories
You will find dot files, the read me file, and a directory labelled 'Homework' when you open this directory. The actual homework files are found within the 'Homework' file.

## Homework Folder
Within the homework folder, there is a directory for each homework/lab assignment that we are doing. All submitted materials will be found in their corresponding Git folder.

- Homework 1+2 are both a single file: 01_homework_Prall

- Homework 3 is a single file: 03_homework_Prall

- Homework 4 is a folder. It contains an example html file for the reads, the sbatch file I used in Tempest, and a markdown file where I responded to the homework questions.

- Homework 5 is a folder. It contains the sbatch file that I used to align the reads and a markdown file where I summarize the reads.
