# BIOE591 Coursework Repository

## Description
This repository is where I will store and edit my coursework for BIOE 591: Genomics for Ecology & Evolution

## Directories
You will find dot files, the read me file, and a directory labelled 'Homework' when you open this directory. The actual homework files are found within the 'Homework' file.

## Homework Folder
Within the homework folder, there is a directory for each homework/lab assignment that we are doing. All submitted materials will be found in their corresponding Git folder.

- Homework 1+2 are both a single file: 01_homework_Prall

- Lab 3 is a single file: 03_homework_Prall

- Lab04 is a folder that contains the materials from homework 4. It contains an example html file for the reads, the sbatch file I used in Tempest, and a markdown file where I responded to the homework questions.

- Lab05 is a folder that contains the materials from homework 5. It contains the sbatch file that I used to align the reads and a markdown file where I summarize the reads.

- Lab06 is a folder that contains the materials from homework 6. It contains the sbatch file that I used to find and quantify variants and a text file that details the summary of that analysis.

- Lab07 is a folder that contains the materials from homework 7. It contains the sbatch file that I used to filter and produce pi-values for a multi-sample vcf file. It also contains a markdown file, where I detail my filtering choices and report and interpret the average pi values for this analysis.

- Lab08 is a folder that contains the materials from homework 8. It contains two snakefiles, two snakemake reports (as HTML files), and the dry run output. v1 represents how I intended to run the code for this lab. v2 represents what actually was able to run.

- Lab09 is a folder that contains the materials from homework 9. It contains the sbatch and output from a ngsRelate run and the R script used to run a coancestry() analysis. I have written up the differences between the two analyses at the bottom of the R script.

- Lab10 is a folder that contains the materials from homework 10. It contains the sbatch and R script used to run an admixture analysis and the pngs of the resulting figures. Figures are named by the k value chosen (e.g. PCA_k2.png is the PCA analysis when K was set to 2). Interpretation of the results can be found at the end of the R script.

- I opted to skip homework #11 in favor of homework number 13.

- Lab12 is a folder that contains the materials from homework 12. It contains a single analysis in two forms: a markdown file and the knitted pdf. Both files contain the script, plots, and interpretations for a genome scane.

- Lab13 is a folder that contains the materials from homework 13. It contains the sbatch and R scripts that I used to generate a phylogeny, which is also contained in the folder as the png. Interpretations of the phylogeny are found at the bottom of the R script.
